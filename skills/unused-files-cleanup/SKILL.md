# 目录未使用文件清理

该技能用于在本仓库中安全清理**任意目标目录**下未被使用的文件，强调“先 dry-run，再删除”。

## 何时使用

- 用户要求清理某个目录下的未使用文件（例如 `src/components`、`src/pages`、`src/utils`）
- 用户提到“死代码文件清理”“删除无引用文件”“unused files in <directory>”
- 需要按照多端规则（RN/H5/小程序）判断可达性

## 输入参数

- `targetDirectory`：要扫描和清理的目录（必填）
- `allowDeleteSuspected`：是否允许删除“疑似未使用”组（默认 `false`）

## 判定口径

1. 搜索引用：`import` / `require` / `import()`
2. 识别导出链：`index.ts`/`index.tsx` barrel re-export
3. 结合多端入口解析：
   - `*.rn.tsx` / `*.h5.tsx` / `*.weapp.tsx` / `*.tsx` / `*.ts`
4. 输出两组候选：
   - 高置信未使用：全仓不可达
   - 疑似未使用：仅目录内部互引，上游无消费

## 标准流程

1. **Dry-run 扫描**
   - 基于 `targetDirectory` 进行只读扫描
   - 只读收集候选，不删除文件
   - 输出每个候选的证据（命中/未命中、导出链断点）
2. **用户确认**
   - 先确认是否删除“高置信组”
   - 再按 `allowDeleteSuspected` 或用户确认决定是否删除“疑似组”
3. **分批删除**
   - 第一批：高置信组
   - 第二批：疑似组（仅在明确同意后）
4. **删除后校验**
   - 再次扫描引用，确认无悬空导入
   - 执行类型/构建相关检查（如 `yarn -s tsc --noEmit`）
   - 汇总“已删文件 + 校验结果 + 残余风险”

## 输出模板

```markdown
## Dry-run 结果
- 目标目录：`<targetDirectory>`
- 高置信未使用：
  - `<targetDirectory>/...`
- 疑似未使用：
  - `<targetDirectory>/...`

## 删除执行
- 已删除高置信组：N 个
- 已删除疑似组：M 个

## 校验
- 引用扫描：通过/失败（附要点）
- 类型检查：通过/失败（附错误摘要）

## 风险提示
- 动态 require 或构建注入引用可能导致静态分析漏判
```

## 注意事项

- 默认不直接删：必须先给 dry-run 清单并获得确认
- 删除操作优先小步进行，避免一次性大范围误删
- 若发现可能涉及运行时动态加载，先升级为“疑似组”，交由用户决策
