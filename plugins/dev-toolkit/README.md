# dev-toolkit

瓜子前端通用开发工具技能包。

## Skills

| Skill | 说明 |
|:------|:-----|
| `figma-png-export` | 通过 Figma API 导出 PNG |
| `bdd-requirement-generator` | 产品需求转 BDD 文档 |
| `unused-files-cleanup` | 多端入口下的未使用文件清理 |
| `method-jsdoc-comments` | 方法 JSDoc 注释规范 |

## 使用

可在任意前端仓库启用；`figma-png-export` 需配置 `FIGMA_ACCESS_TOKEN`。
