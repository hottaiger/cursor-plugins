# detail-taro

detail-taro3 商详页开发的 Cursor 技能包。

## Skills

| Skill | 说明 |
|:------|:-----|
| `detail-taro3-coding-standards` | 编码规范与 PR 审查 |
| `koala-skill` | `@guazi-fe/koala-ui` 组件选型 |
| `cross-utils-skill` | `@guazi-fe/cross-utils` 函数速查 |
| `image-resource-center` | 图片资源与 CDN 规范 |
| `tracker-detail` | 商详埋点 |
| `rn-event-handling` | RN 事件处理 |
| `unit-test-skill` | 单元测试写法 |
| `testable-frontend-design` | 可测试前端设计 |

## 使用

在 detail-taro3 仓库中启用本插件，Agent 会在商详相关任务中自动匹配上述 skills。
