# guazi-workflow

瓜子内部研发工作流技能包。**需内网 MCP 与 CLI 权限。**

## Skills

| Skill | 说明 |
|:------|:-----|
| `feishu-requirement-pool` | 飞书需求池：按 SFE 分支同步 Jira 到多维表格 |
| `changelog-updater` | 根据 Jira 更新 Changelog |

## 前置依赖

- `guazi-jira-mcp`
- `lark-cli`（飞书多维表格）
- git 分支命名 `SFE-xxxxx`

## 使用

仅在已配置上述工具的环境中启用本插件。
